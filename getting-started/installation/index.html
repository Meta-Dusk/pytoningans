    Installation & Requirements

    PyToNingans is initially built for Windows environments, which means that I haven't tested the app in other Operating Systems. Setting up the app is very straightforward, as you only need to download the installer in the Releases section in the GitHub repository!

    Prerequisites

    Before installing PyToNingans, ensure you have:

    • Operating System: Windows 10 or Windows 11 (64-bit).

    That's mostly it for now.

    Setup Instructions

    You would usually see the setup instructions in the note included in the release, but by default, what you would expect is basically an executable named; PyToNingans-vX.X.X-Win64-Installer.exe. The Xs simply represents the version numbers. You will also expect another executable, which is similary named; PyToNingans-vX.X.X-with-console-Win64-Installer.exe. This version simply just has a console built-in (which is just for debugging). You don't really need this version, unless you need to see the logs of the app.

    Once you download the installer, you can just simply follow the setup wizard, and that's it! It's that easy :)

    Updates

    For now, there's no automatic downloading of updates, but updating the app isn't that difficult. You can just simply reinstall the app with the latest version of the installer, and it will handle updating it! This is all thanks to Inno Setup Compiler :)
