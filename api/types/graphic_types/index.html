    ResolvableTexture 

    ResolvableTexture = Union[
    ITexture, str, TupleTextureDescriptor
]

    You can procedurally create textures by passing in either a tuple or a string. Refer to the explanations below:

    Syntax

    shape : str

    Choose between: "dot, square, ring, glow_circle, or glow."

    radius : int size : int color : ColorType

    Can be of type `IColor`, `str`, or `Colors`.

    core_color : ColorType outer_color : ColorType

    Formatting

    Passing a tuple will need the first member as the shape. You can omit the rest, which will have defaults.

    The following possible formats are (with shape filled in):

    ("dot", radius, color); defaults to radius=6, color="white"

    ("square", size, color); defaults to size=10, color="white"

    ("ring", radius, color); defaults to radius=10, color="white"

    ("glow_circle" or "glow", size, core_color, outer_color); defaults to

    size=15, core_color="white", outer_color="transparent"

    An alternative is a oneline string, that is colon-separated. Except, it must start with 'procedural:'.

    "procedural:dot:radius:color"

    "procedural:square:shape:color"

    "procedural:ring:radius:color"

    "procedural:glow_circle:radius:core_color:outer_color"

    "procedural:glow:radius:core_color:outer_color"
