# Quickstart Guide

Get up and running with PyToNingans in minutes!

---

## The Control Panel

When PyToNingans launches, the central **Control Panel** appears. It provides intuitive modular controls divided into two main panels:

```text
+-------------------------------------------------------+
| Control Panel                                     [X] |
+---------------------------+---------------------------+
| Spawning & Placement      | Live Stats & Controls     |
| - Entity Selector         | - Active Entities: 3      |
| - Spawn Area Filter       | - FPS / System Performance|
| - [Spawn Selected] Button | - Kill All / Pause All    |
|                           +---------------------------+
|                           | Management & Settings     |
|                           | - [Mod Browser]           |
|                           | - [Manage Mods]           |
|                           | - [Settings]              |
|                           | - [Theme]  [Shutdown]     |
+---------------------------+---------------------------+
```

---

## 1. Spawning Your First Entity

1. Look at the left pane (**Spawning and Placement**).
2. Select any installed mod entity or pre-packaged companion from the list.
3. Choose your desired spawn boundary:
    - **Full Primary Screen**: Spawns anywhere across your monitor.
    - **Active Desktop Bounds**: Prefers empty space away from foreground taskbars.
4. Click **Spawn Entity**. Your character will drop directly onto your desktop!

---

## 2. Interacting With Characters

- **Left Click & Drag**: Pick up any entity and throw or reposition them anywhere across your monitors.
- **Right Click**: Opens the **Entity Context Menu** to inspect current stats, view assigned animations, trigger special actions, or despawn the character.
- **Desktop Windows**: Drag a desktop window (like Notepad or a browser) underneath a falling character; watch them land and walk across the top title bar of your application!

---

## 3. Managing Mods and Settings

- **Mod Browser**: Click **Mod Browser** to discover, download, and rate community creations.
- **Manage Mods**: Open the local Mod Manager Hub to toggle, edit, or create new sprite sheets.
- **Settings**: Open the **Settings** menu to customize health bars, damage popups, window physics, and enable Developer Mode.
